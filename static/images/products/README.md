## How to get the images
1. Go to the product page (Amazon, Grenaro, or official site)
2. Right-click the main product image → Save image as
3. Rename it to match the filename in the table above
4. Drop it in this folder
5. Commit and push — the image will appear on the /links page automatically

> If an image file is missing, the card still renders correctly — the image slot is hidden gracefully.
